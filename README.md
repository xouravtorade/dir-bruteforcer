# dir-bruteforcer\n\nA small, rate-limited directory checker built in Python for authorized security testing. It checks a target website against a custom wordlist and reports possible paths based on HTTP responses.\n\n## Features\n\n- Rate-limited sequential scanning\n- Custom wordlist support\n- Reports successful (2xx) and redirect (3xx) responses\n- Displays HTTP status codes, response sizes, and redirect targets\n- Skips blank lines, comments, and duplicate entries\n- Request timeout and graceful error handling\n- Colorized terminal output\n\n## Requirements\n\n- Python 3.10+\n- requests\n- colorama\n\n## Installation\n\n```bash\npip install requests colorama\n```\n\n## Usage\n\n```bash\npython3 dir_bruteforcer.py\n```\n\nWhen prompted, enter a target and wordlist:\n\n```text\nEnter target URL: https://example.com\nEnter wordlist file: dir.txt\n```\n\n## Wordlist format\n\nPut one directory or file path per line. Blank lines and lines beginning with # are ignored.\n\n```text\nadmin\nlogin\nimages\ncss\njs\n```\n\n## Responsible use\n\nUse this tool only against websites you own or have explicit permission to test. Keep the built-in delay enabled, respect the target's policies, and do not use it for authentication attacks, password guessing, evasion, or unauthorized scanning.\n
