# dir-bruteforcer\n\n> A simple, rate-limited website directory checker for authorized security testing.\n\n## What does it do?\n\nThis tool takes a website URL and a list of common paths such as `admin`, `login`, or `images`. It sends one normal HTTP `GET` request per path and tells you which paths return a successful response or a redirect.\n\nIt does **not** log in, guess passwords, exploit vulnerabilities, hide its traffic, or bypass security controls.\n\n## Example\n\nIf `dir.txt` contains:\n\n```text\nadmin\nlogin\nimages\ncss\n```\n\nThe tool checks:\n\n```text\nhttps://example.com/admin\nhttps://example.com/login\nhttps://example.com/images\nhttps://example.com/css\n```\n\n## Requirements\n\n- Python 3.10 or newer\n- `requests`\n- `colorama`\n\n## Installation\n\nOpen a terminal in the project folder and run:\n\n```bash\npip install requests colorama\n```\n\n## Run the scanner\n\n```bash\npython3 dir_bruteforcer.py\n```\n\nThe program asks:\n\n```text\nEnter target URL: https://example.com\nEnter wordlist file: dir.txt\n```\n\n## Understanding the output\n\n```text\n[+] Found: https://example.com/images [301, 318 bytes] -> https://example.com/images/\n[-] 404: https://example.com/login\n```\n\n- `[+] Found` means the server returned a `2xx` success or `3xx` redirect response.\n- `[-] 404` means that path was not found.\n- `403` means the server understood the request but refused access; it may still be a real path.\n- The tool shows response size and redirect location when available.\n- The scanner waits 0.5 seconds between requests and stops safely on errors or Ctrl+C.\n\n## Wordlist format\n\nUse one path per line. The tool ignores blank lines, comments starting with `#`, and duplicate entries.\n\n```text\n# Common website paths\nadmin\nlogin\ndashboard\nimages\ncss\njs\n```\n\n## Authorized use only\n\nOnly scan websites you own or have explicit permission to test. A public website is not automatically safe to scan. Do not use this tool for password guessing, authentication attacks, vulnerability exploitation, evasion, or unauthorized testing. Respect the website owner's rules and rate limits.\n\n## Project files\n\n- `dir_bruteforcer.py` - the scanner\n- `dir.txt` - starter wordlist\n- `pyproject.toml` - Python project metadata\n- `uv.lock` - locked dependency versions\n- `.gitignore` - local files excluded from Git\n
